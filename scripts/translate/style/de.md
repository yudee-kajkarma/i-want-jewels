# German (de)

- **Address the reader as `Sie`.** Never `du`. This is a jewellery retailer, not
  a streetwear brand.
- Capitalise all nouns. This is the most common failure in machine-translated
  German copy — check every noun in every sentence.
- Compound nouns are written closed, not spaced: `Tennisarmband`, not
  `Tennis Armband`. Hyphenate only when the compound mixes an English loanword
  with a German noun (`Statement-Ohrringe`, `Halo-Fassung`).
- Decimal comma, thousands point: `1,5 Karat`.
- German runs ~20% longer than English. Meta titles and descriptions will need
  active shortening, not literal rendering — this is expected, do it.
- `Karat` is weight for gems; gold purity is also `Karat` in German. Where the
  English distinguishes carat (weight) from karat (purity), disambiguate with
  `Karat (Gewicht)` / `Karat (Goldlegierung)` only if the source does.
